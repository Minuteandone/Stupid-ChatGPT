What counts as a stem?

Each DS SSEQ can use up to 16 sequencer tracks. This page renders each active SSEQ track separately using the game’s own instrument banks and wave archives. Silent tracks are discarded automatically.

For looping music, the page keeps the one-time intro and then renders exactly the number of complete loops you choose. Non-looping sequences render once. A hidden safety cap prevents malformed sequences from running forever.

The ROM is processed locally with nitro-fs. This site does not include ROMs or game audio.
